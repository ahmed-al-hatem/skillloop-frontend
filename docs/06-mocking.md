# 06 · Mocking with MSW

**English** · [العربية](06-mocking.ar.md)

[MSW](https://mswjs.io) intercepts real `axios` requests in the browser and answers with fake data. Our code doesn't know the difference — when the backend is ready we just switch `VITE_USE_MOCKS=false`, nothing else changes.

## How it's wired

```
main.tsx ──(VITE_USE_MOCKS=true)──► mocks/browser.ts ──► mocks/handlers.ts
                                                         ├─ ...authHandlers
                                                         └─ ...<feature>Handlers
```

- `public/mockServiceWorker.js` is generated by MSW (`npx msw init public`) — don't edit it.
- Requests without a handler pass through to the real API.
- In production builds with `VITE_USE_MOCKS=false`, MSW and mock data aren't loaded.

## Adding a mock for a feature

Easiest: `/add-endpoint` in Claude Code / Codex. By hand:

**1. Data** — `features/services/mocks/services.data.ts`

```ts
import type { Service } from '../schemas/service.schema';

export const services: Service[] = [/* realistic data, mix Arabic and English names */];
```

**2. Handler** — `features/services/mocks/services.handlers.ts`

```ts
import { delay, http, HttpResponse } from 'msw';
import { env } from '@/config/env';
import { services } from './services.data';

export const servicesHandlers = [
  http.get(`${env.API_URL}/services`, async () => {
    await delay(400);
    return HttpResponse.json({
      data: services,
      meta: { page: 1, pageSize: 20, total: services.length },
    });
  }),
];
```

**3. Register** — one line in `src/mocks/handlers.ts`:

```ts
import { servicesHandlers } from '@/features/services/mocks/services.handlers';

export const handlers: RequestHandler[] = [...authHandlers, ...servicesHandlers];
```

## Testing error and empty states

Temporarily change a handler (don't commit it):

```ts
// Error
return HttpResponse.json(
  { error: { code: 'INTERNAL_ERROR', message: 'Server error' } },
  { status: 500 },
);
// Validation
return HttpResponse.json(
  {
    error: {
      code: 'VALIDATION_ERROR',
      message: 'Some fields are invalid',
      details: [{ field: 'email', message: 'Already taken' }],
    },
  },
  { status: 400 },
);
// Empty list
return HttpResponse.json({ data: [], meta: { page: 1, pageSize: 20, total: 0 } });
```

## Rules

- Responses must match [05 · API contract](05-api-contract.md) exactly (same envelope, same fields).
- Type the data with the feature's schema type so it can't drift.
- **Never** import `*.data.ts` from components or pages.
- **Never** export `mocks/` from a feature's `index.ts`.
