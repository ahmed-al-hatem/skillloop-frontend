# 08 · المساعدات الذكية (Claude Code وCodex)

[English](08-ai-assistants.md) · **العربية**

بدل ما تحفظ أوامر Git، رتّبنا الشغل حوالين **Claude Code** و**Codex**. الاتنين بيمشوا على نفس قواعد المشروع.

## وين القواعد

| الملف             | مين بيقرأه            | شو فيه                                        |
| ----------------- | --------------------- | --------------------------------------------- |
| `AGENTS.md`       | Codex (تلقائياً)       | **كل** قواعد المشروع، بمكان واحد              |
| `CLAUDE.md`       | Claude Code (تلقائياً) | بيستورد `@AGENTS.md` + ملاحظات خاصة بـ Claude |
| `.agents/skills/` | Codex                 | الـ skills (النسخة الأصلية)                   |
| `.claude/skills/` | Claude Code           | نسخة عن `.agents/skills/`                     |

القواعد مكتوبة **مرة وحدة** بـ `AGENTS.md`. لتغيّر قاعدة، عدّل `AGENTS.md` بس (بـ PR).
لتغيّر skill، عدّل `.agents/skills/<name>/SKILL.md`، بعدين شغّل `npm run skills:sync` وارفع المجلدين.

## الـ Skills

| الأمر            | شو بيعمل                                                                                                 |
| ---------------- | -------------------------------------------------------------------------------------------------------- |
| `/start-task 12` | بيقرأ issue رقم 12، بيحدّث `main`، وبيفتح فرع باسم صحيح (`feat/12-…`)                                     |
| `/new-feature`   | بيعمل مجلد feature حسب الهيكلية وبيسجّل الـ route (سطر واحد)                                              |
| `/add-endpoint`  | بيعمل schema وapi وhook وmock دفعة وحدة، و**رافض يخترع endpoint مو موجود بالعقد**                        |
| `/finish-task`   | بيعمل check وcommit، بيدمج آخر نسخة من `main`، بيرفع، وبيفتح PR. **ممنوع عليه يعمل merge أو force push** |
| `/review-pr 15`  | بيجيب PR رقم 15، بيشغّله، بيمشي معك بـ شغّل · جرّب · شيّك، وبيكتبلك مسودة التعليقات                          |

بـ Codex اطلب بالكلام ("start task 12"، "finish the task") أو استخدم `$start-task`، وهو بيختار الـ skill من وصفها.

## يوم عادي

```
/start-task 12                   → صرت على فرع feat/12-matching-list
"ابني كرت الشريك حسب الـ issue"
/add-endpoint GET /categories
npm run dev → شوف النتيجة بالمتصفح
/finish-task                     → انفتح PR وانطلبت مراجعة من زميلك
```

لمراجعة شغل زميلك: `/review-pr 15`.

## قواعد أمان بيلتزموا فيها

- ما في commit أو push على `main`، ولا `--force`، ولا merge للـ PRs.
- أوامر Git الخطيرة (`reset --hard`، `clean`، حذف فروع) بس بعد ما يشرح ويسألك.
- ما في endpoints مخترعة، العقد بـ [05](05-api-contract.ar.md) أولاً.
- ما بيرفع `.env` أبداً.

## نصائح

- **اقرأ شو غيّر** قبل `/finish-task`، إنت صاحب الكود مو الذكاء الاصطناعي.
- اعطيه رقم الـ issue، هو بيقرأها ليفهم المطلوب.
- إذا بدو يعدّل `shared/` أو ملف مركزي، تأكد إنه زميلك مو عم يعدّل عليه هلق.
- في شي مو واضح؟ اطلب منه يشرحلك الخطأ بكلام بسيط قبل ما يصلّحه.
