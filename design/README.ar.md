# هوية SkillLoop

[English](README.md) · **العربية**

هوية البراند وطريقة استخدامها بالواجهة. ملفات المصمم الأصلية موجودة بـ [`source/`](source/). لا تعدّل عليها، واطلب نسخة جديدة من المصمم إذا لزم.

## الألوان

| الاسم   | Hex       | الـ Token                                  | استخدمه لـ                                               |
| ------- | --------- | ------------------------------------------ | -------------------------------------------------------- |
| بنفسجي  | `#8038FF` | `primary`، `ring`                          | الأزرار الأساسية، الروابط، حلقة الـ focus، الحالة النشطة |
| فوسفوري | `#B8ED50` | `secondary`                                | الأزرار الثانوية، التمييز، الشارات                       |
| رمادي   | `#2D2B35` | `foreground`، `secondary-foreground`       | النصوص، الأسطح الغامقة (الهيدر/الفوتر، الواجهة الرئيسية) |
| أبيض    | `#FFFFFF` | `background`، `card`، `primary-foreground` | خلفية الصفحة، الكروت، النص فوق البنفسجي                  |
| كحلي    | `#0B2349` | `background` جوا `data-theme="admin-dark"` | الأسطح الغامقة: خلفية لوحة الإدارة                       |

لوحة الإدارة غامقة: `data-theme="admin-dark"` (بـ `index.css`) بيحوّل الـ tokens لأسطح كحلية ونص أبيض، وثيم MUI بيستخدم نفس الألوان. درجات الكحلي من لوحة الهوية: `#0B2349` `#163F80` `#1F4C94` `#275DB3` `#3D78D7`.

بقية الـ tokens مخلوطة من ألوان الهوية بـ [`src/styles/index.css`](../src/styles/index.css): `muted` (رمادي 4%)، `muted-foreground` (رمادي 72%)، `accent` (بنفسجي 8%، لخلفية الـ hover)، `border` (رمادي 12%)، `input` (رمادي 16%). الأحمر `destructive` مو من ألوان الهوية، بس خليناه للأخطاء.

**القواعد**

- بالكومبوننتات استخدم كلاسات الـ tokens متل `bg-primary` و`text-foreground` و`bg-secondary`، ولا تكتب hex أبداً. للتسويق والرسومات بس في كمان `bg-brand-purple` و`bg-brand-lime` و`bg-brand-charcoal`.
- **ممنوع تكتب نص فوسفوري على خلفية بيضا.** التباين تقريباً 1.4:1، يعني ما بينقرأ. الفوسفوري للـ **خلفية** والنص فوقه رمادي (تقريباً 10:1).
- الأبيض فوق البنفسجي تباينه تقريباً 5.4:1، وبينجح بمعيار WCAG AA للنص العادي. والرمادي فوق الأبيض تقريباً 14:1.
- إذا بدك تغيّر لون، عدّل بس متغيرات `--brand-*` بـ `index.css`، وكل الباقي بيتحدّث لحاله.

## الخطوط

| الخط                  | اللغة                    | الحزمة                                  |
| --------------------- | ------------------------ | --------------------------------------- |
| Noto Sans Arabic (UI) | العربي، وهو الخط الأساسي | `@fontsource-variable/noto-sans-arabic` |
| Noto Sans             | اللاتيني وباقي اللغات    | `@fontsource-variable/noto-sans`        |

- الخطوط **محمّلة من عنا** عن طريق npm، وما في شي بيجي من Google. يعني التطبيق بيشتغل بدون نت وما بيبعت بيانات لطرف تالت. وهي خطوط variable، فكل الأوزان من 100 لـ 900 موجودة (`font-normal`، `font-medium`، `font-semibold`، `font-bold`…).
- المتصفح بينزّل بس الجزء اللي بتحتاجه الصفحة (`unicode-range`). إذا النص كله عربي، ملف اللاتيني ما بينزل.
- **عن كلمة "UI":** نسخة Noto Sans Arabic **UI** هي نفس التصميم بس ارتفاع السطر فيها أصغر. Google وFontsource ما عادوا ينشروها لحالها لأنها اندمجت بـ Noto Sans Arabic. إذا حسّيت ارتفاع السطر كبير بالأزرار أو الحقول، استخدم `leading-tight` أو `leading-snug`.
- الخط مضبوط من قبل على أنه `font-sans` (الافتراضي للـ `body`)، فما في داعي تضيف شي.

## اللوغو

### جوّا التطبيق: `src/shared/assets/brand/`

| الملف                 | الخلفية                  | الألوان             |
| --------------------- | ------------------------ | ------------------- |
| `logo-on-light.svg`   | أبيض أو فاتح             | رمادي + بنفسجي      |
| `logo-on-dark.svg`    | رمادي أو غامق            | أبيض + بنفسجي       |
| `logo-on-primary.svg` | بنفسجي                   | أبيض + رمادي        |
| `logo-mono-black.svg` | طباعة بلون واحد          | أسود                |
| `logo-mono-white.svg` | فوق صورة أو خلفية مزحومة | أبيض                |
| `app-icon.svg`        | أيقونة مربعة (الحلقتين)  | مربع رمادي + بنفسجي |

ملفات اللوغو مقصوصة على قد الكلمة مع مسافة فاضية صغيرة. استخدمها كصورة، وVite بيحوّلها لرابط:

```tsx
import logoUrl from '@/shared/assets/brand/logo-on-light.svg';

<img src={logoUrl} alt="SkillLoop" className="h-8 w-auto" />;
```

- حدّد **الارتفاع بس** (`h-6` لـ `h-10` بالهيدر) وخلّي `w-auto` حتى ما يتمطّ اللوغو.
- اللوغو كلمة لاتينية، فلا تعكسه ولا تقلبه بالـ RTL.
- أقل ارتفاع 20px، وإذا بدك أصغر استخدم `app-icon.svg`.
- لا تغيّر لون اللوغو بالـ CSS، اختار وحدة من النسخ اللي فوق.

### للمتصفح والموبايل: `public/`

| الملف                   | المقاس       | لشو                                                      |
| ----------------------- | ------------ | -------------------------------------------------------- |
| `favicon.svg`           | vector       | تبويب المتصفح (المتصفحات الحديثة)                        |
| `favicon.ico`           | 16 / 32 / 48 | تبويب المتصفح (المتصفحات القديمة، ويندوز)                |
| `apple-touch-icon.png`  | 180×180      | الشاشة الرئيسية بالآيفون والآيباد (خلفية رمادي كاملة)    |
| `icon-192.png`          | 192×192      | أندرويد / PWA                                            |
| `icon-512.png`          | 512×512      | أندرويد / PWA، شاشة البداية                              |
| `icon-maskable-512.png` | 512×512      | أيقونة أندرويد المتكيّفة (المنطقة الآمنة 80%)             |
| `og-image.png`          | 1200×630     | معاينة الرابط (واتساب، X، فيسبوك، Slack…)                |
| `site.webmanifest`      | —            | اسم التطبيق وألوانه وأيقوناته لـ "إضافة للشاشة الرئيسية" |

كل هالملفات مربوطة من `index.html`.
